# SmartEye Price Manager — Windows

Electron wrapper around `tools/calc-app` (the same app as smarteye.am/calc and the Android APK).
Built on GitHub Actions (`.github/workflows/android-apk.yml`, job `windows`) and attached to the same
GitHub release as the APK.

Installer: https://github.com/vardanyannarek00/smarteye-site/releases/latest/download/SmartEye-PriceManager-Setup.exe
